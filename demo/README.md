# Synthetic example

The ten 96 × 64 grayscale images and masks in this directory are generated by
`generate.py`. They contain simple sinusoidal traces and synthetic noise. No
field FMI data or expert annotations are used.

From the repository root, install `requirements.txt`, then run:

```bash
bash demo/run.sh
```

This runs one CPU training epoch of a reduced APGRA-Net, selects a threshold on
two validation images, and evaluates two test images. The output appears in
`results/synthetic_demo/`, which Git excludes. Demo scores are a pipeline smoke
check and do not correspond to the paper's field FMI scores. To rerun, move
`results/synthetic_demo/` aside and run the command again.
