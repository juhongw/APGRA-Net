Create `session_v1/train.jsonl`, `val.jsonl`, and `test.jsonl` for your own FMI data. Each line is a JSON object as shown in `example.jsonl`: `sample_id` identifies the sample; `group_id` and `session_id` record its acquisition grouping; `image_rel` and `mask_rel` are image and mask paths relative to the FMI data root. Keep each acquisition session in only one split. Then run `python tools/build_label_efficiency_manifests.py` to create the training-label subsets.
